# About registries, repositories, and artifacts

This resource explains the core concepts behind Azure Container Registry, including how registries, repositories, and artifacts are organized and used.

## Why it matters

Understanding the structure of ACR helps you design scalable and manageable container workflows for AI workloads, microservices, and deployment pipelines.

## Key concepts

- Registry: the top-level container storage service
- Repository: a logical collection of image versions
- Artifact: the actual image or OCI-compliant content stored in a repository
