# Best practices for Azure Container Registry

This resource outlines recommended patterns for organizing images, controlling access, and maintaining efficient registry operations.

## Core recommendations

- Use namespaces and clear repository naming
- Separate environments such as dev, staging, and prod
- Monitor storage and retention policies
- Use geo-replication when your workloads are global
- Plan for version control and rollback strategy
