# Azure Container Registry service tiers

This document describes the available ACR service tiers and the differences between them.

## Overview

ACR supports Basic, Standard, and Premium tiers. The tier you choose affects throughput, storage, geo-replication, and enterprise features such as private endpoints.

## When to choose each tier

- **Basic**: development and learning scenarios
- **Standard**: production workloads with moderate scale
- **Premium**: enterprise-grade features such as geo-replication and private networking
